# Sinema – Cinema Management System

A modular Java-based **Cinema Management System** designed to manage movie listings, show schedules, seating availability, and ticket booking operations. Built using Maven for dependency management and structured with clear separation of business logic and data access.

---

## 📌 Features

- Manage movie listings
- Define show times and schedules
- Check seat availability
- Book and manage tickets
- Organised layered architecture

---

## 🛠️ Technologies Used

- Java
- Maven
- JDBC
- MySQL
- OOP Principles
